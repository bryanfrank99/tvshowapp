Coloca aquí los archivos de instalación compilados con los siguientes nombres:

1. TVShow-TV.apk
   -> Aplicación para Android TV, Google TV, Fire TV Stick y TV Boxes.

2. TVShow-Mobile.apk
   -> Aplicación para teléfonos móviles y tablets Android.

3. TVShow-Setup.exe
   -> Instalador de escritorio para Windows 10 y 11.

La página web (index.html) descargará automáticamente estos archivos desde esta misma carpeta sin requerir ningún servicio externo ni GitHub.
